# O que cada agente fez e por quê

Comece pelos relatos curtos. Eles explicam as escolhas do site para quem está aprendendo.

- [Produto](produto.md): o que a página precisa explicar e o que vamos comparar.
- [Design](designer.md): como as telas foram organizadas e por que testar outra ordem.
- [Frontend](frontend.md): quais ferramentas constroem as páginas e para que servem.
- [Backend](backend.md): por que este site ainda não precisa de um sistema para guardar dados.
- [Observador](observador.md): o que foi conferido e o que ainda falta.

Para ver as telas e experimentar os caminhos, abra [a comparação no Figma](https://www.figma.com/design/gSo2f1TKL4c7w4trJgQxE2?node-id=6-3). O roteiro está em [Como comparar os protótipos](../11-prototipagem.md).

Os relatos de análise de 19/10 não significam que os agentes executaram novamente a implementação de 16/10. A execução dos testes e a revisão desta entrega ficam registradas pelo orquestrador nas evidências da rodada.
