# Frontend — 19/10/2026

## O que usei e por quê

Usei HTML para organizar títulos, textos, imagens e links; CSS para definir cores, espaços e adaptação ao celular; e JavaScript para abrir o menu e trocar o tema. Essas três ferramentas atendem ao protótipo sem instalar ferramentas extras.

## Como organizei

A página inicial apresenta as aulas, a professora e o próximo contato. Separei os aprovados em outra página para dar espaço às histórias. Mantive fontes nas informações sobre Gisele e nos comentários dos alunos.

Preparei duas combinações de cores, clara e escura, com rosa. A escolha fica lembrada durante a navegação naquela sessão. No celular, o menu fecha com Escape e devolve a seleção ao botão. Sem JavaScript, os links de navegação continuam disponíveis.

## O que conferi

Usei Node.js, que executa JavaScript fora do navegador, nos testes automáticos. Eles procuram links quebrados, arquivos ausentes, diferenças nos comentários originais e problemas nas combinações de cores.

Nesta rodada apenas reli o código e o registro anterior. Não alterei arquivos nem executei testes ou navegador. O registro de 16/10 informa sete testes aprovados; isso é uma evidência anterior. Uma nova execução do orquestrador fica separada nas evidências de 19/10.
