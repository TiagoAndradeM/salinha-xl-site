## Contraste conferido

Designer calculou; orquestrador conferiu valores do CSS. Para cada canal normalizado c: c/12,92 se c <= 0,04045; caso contrário ((c+0,055)/1,055)^2,4. L = 0,2126R + 0,7152G + 0,0722B; razão = (L maior+0,05)/(L menor+0,05).

| Uso | Texto / fundo | Razão calculada |
|---|---|---|
| `.hero-footnote` | #787d73 / #f6f1eb | 3.7553693493181934 |
| Rodapé | #757971 / #f6f1eb | 3.9537380948275516 |
| `.card-index` | #858980 / #fffcf7 | 3.48535424728899 |
| `.card-tag` | #7f857c / #fffcf7 | 3.698184171650477 |

Cálculo de valores declarados, sem amostragem de pixels. Fontes primárias consultadas: [W3C contraste](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html), [reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html), [tamanho de alvo](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html).
