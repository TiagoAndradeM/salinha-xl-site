# Onde estamos

Atualizado em 19/10/2026.

Escolhemos comparar a organização das páginas no Figma antes de mudar o site. A mantém a sequência atual. B aproxima reforço e preparação para provas da chegada e reorganiza os aprovados. As duas usam a mesma paleta clara. B ainda é uma tentativa; não temos uma versão vencedora.

O [arquivo editável no Figma](https://www.figma.com/design/gSo2f1TKL4c7w4trJgQxE2?node-id=6-3) tem oito telas principais, para computador e celular, com quatro entradas de apresentação.

Produto e design propuseram comparar por onde a pessoa começa. Frontend preservou o site. Backend manteve a escolha de não criar um sistema para guardar dados: a apresentação atual não precisa dele. Veja os [relatos de cada agente](relatorios/README.md).

O orquestrador rodou novamente os testes do site: sete passaram, sem falhas. Também conferiu as cinco configurações dos agentes. Eu li essas provas, conferi as diferenças dos arquivos e olhei as duas imagens finais disponíveis.

Falta revisar todas as telas e percorrer os cliques na apresentação. O navegador pediu login e a integração do Figma chegou ao limite de chamadas. As ligações foram configuradas e corrigidas, mas isso não comprova o percurso completo. Não houve teste com pessoas.

O próximo passo é entrar no Figma e seguir as [três tarefas de comparação](11-prototipagem.md). Depois o dono do projeto escolhe uma mudança pequena para o site. O envio desta rodada ao GitHub já está autorizado; sua execução ainda será registrada pelo orquestrador.
